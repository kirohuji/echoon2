# GuideReady / 导游说 平台 UI 配色规范

## 1. 整体色彩定位

平台整体应呈现：

**国际化、简洁、可信赖、轻科技、带一点东方温度。**

配色不走传统中国风的红金路线，而是以 **深蓝作为品牌底色**，体现专业、稳定和数字化；以 **白色作为主要内容色**，保持清晰和现代；以 **珊瑚橙红作为情绪点缀**，表达“声音、太阳、启发、开口说”的品牌记忆点。

整体视觉关键词：

**深蓝背景 / 白色留白 / 橙红点睛 / 简洁线条 / 现代国际感**

---

## 2. 品牌主色

### 2.1 品牌深蓝 Primary Navy

用于品牌背景、首页首屏、导航栏、重要品牌展示区。

```text
Primary Navy：#002E5F
Deep Navy：#002247
Dark Navy：#001A35
```

使用建议：

- Logo 背景、官网首页 Hero 区、登录页、品牌宣传页可大面积使用。
- 后台型功能页面不建议全页面深蓝，否则长时间使用会压抑。
- 深蓝适合作为“框架色”，不适合作为所有内容卡片的底色。

---

### 2.2 主文字白 White

用于深色背景上的主要文字、Logo、图标线条。

```text
Pure White：#FFFFFF
Soft White：#F8FAFF
Muted White：#DDE7F3
```

使用建议：

- 深蓝背景上的标题、按钮文字、主图标使用 `#FFFFFF` 或 `#F8FAFF`。
- 次级说明文字不要用纯白，可用 `#DDE7F3` 降低刺眼感。
- 大段正文避免纯白，建议使用偏柔和的浅灰白。

---

### 2.3 点缀橙红 Coral Red

用于品牌记忆点、关键按钮、当前状态、语音/开始练习等强行动点。

```text
Coral Red：#FF5A45
Coral Hover：#FF725F
Coral Pressed：#E94A36
Coral Light：#FFE6E1
```

使用建议：

- 只用于关键部位，不能大面积铺开。
- 适合用于：开始练习、录音中、播放按钮、重点标签、进度节点、太阳图形。
- 一个页面中橙红面积建议不超过 5%。
- 不建议同时使用太多红色系，否则会像错误提示或警告系统。

---

## 3. 辅助色延展

为了让平台 UI 不只有深蓝、白、橙红，可以延展一组低饱和辅助色。

### 3.1 蓝色辅助色

用于按钮、卡片边框、选中态、链接、信息提示。

```text
Blue 900：#002E5F
Blue 800：#00427F
Blue 700：#005FA8
Blue 600：#1677C8
Blue 100：#EAF4FF
Blue 50 ：#F4F9FF
```

建议：

- `#1677C8` 可作为常规链接色。
- `#EAF4FF` 可作为浅色页面中的信息卡片背景。
- 不要使用过亮的科技蓝，避免破坏 Logo 的沉稳感。

---

### 3.2 中性色

用于正文、分割线、表单、卡片背景。

```text
Text Primary：#1F2D3D
Text Secondary：#5F6F82
Text Tertiary：#8A98AA
Border：#DCE5EF
Divider：#E8EEF5
Page Background：#F5F8FC
Card Background：#FFFFFF
```

建议：

- 平台功能页建议使用浅背景 `#F5F8FC`。
- 卡片使用白色，边框用浅灰蓝。
- 正文不要使用纯黑，建议使用偏蓝灰的深色。

---

## 4. 功能状态色

平台涉及练习、评分、任务、提醒，可以建立清晰的状态色。

```text
Success Green：#18A058
Warning Amber：#F5A623
Error Red：#E5484D
Info Blue：#1677C8
Recording Coral：#FF5A45
```

使用规则：

- 成功、完成、通过：绿色。
- 待提升、提醒、注意：琥珀黄。
- 错误、失败、风险：红色。
- 信息、说明、系统提示：蓝色。
- 录音中、开口说、重点行动：品牌橙红。

注意：  
品牌橙红不要和错误红混用。错误红应更偏正红，品牌橙红应更温暖、更有情绪感。

---

## 5. 页面配色比例

建议采用：

```text
70%：浅色背景 / 深蓝品牌框架
20%：白色卡片 / 蓝灰中性色
10%：品牌橙红与重点蓝色
```

具体应用：

- 官网、登录页、品牌介绍页：可以深蓝占比更高。
- 题库、练习、后台管理页：建议浅色背景为主，深蓝用于顶部栏或侧边栏。
- 练习状态页、模考页：可以局部使用深蓝增强沉浸感。
- 结果页：白底为主，橙红突出分数、建议、下一步行动。

## 6. 关键组件配色规范

### 6.1 顶部导航栏

```text
背景：#002E5F
主文字：#FFFFFF
次级文字：#DDE7F3

```

适合用于官网、练习平台、管理端统一头部。

---

### 6.2 主按钮

用于“开始练习 / 开始模考 / 立即开口说”。

```text

Hover：#FF725F
Pressed：#E94A36

```

要求：

- 主按钮一个页面最多 1 到 2 个。
- 不能把所有按钮都做成橙红色。
- 橙红按钮只给最高优先级操作。

---

### 6.3 次按钮

```text

边框：#DCE5EF
文字：#002E5F

```

适合用于“查看答案 / 返回题库 / 重新练习”。

---

### 6.4 链接按钮

```text
文字：#1677C8
Hover：#005FA8
```

适合用于说明、帮助、跳转、查看详情。

---

### 6.5 卡片

```text

边框：#E8EEF5
标题：#1F2D3D

建议：

- 题库卡片、练习卡片、景点卡片使用白色背景。
- 被选中的题目或模式可以用蓝色边框。
- 当前正在练习或录音中的状态可以用橙红点缀。

---

### 6.6 输入框 / 搜索框

### 6.7 标签 Tag

```

## 8. 深色模式与浅色模式

### 8.1 深色品牌模式

适合：

- 首页
- 登录页
- 品牌展示
- 模考沉浸页
- 结果总结页顶部

```text
背景：#002E5F
主文字：#FFFFFF
次文字：#DDE7F3
按钮：#FF5A45
卡片背景：rgba(255,255,255,0.08)
卡片边框：rgba(255,255,255,0.18)
```

---

### 8.2 浅色功能模式

适合：

- 题库列表
- 练习详情
- 用户中心
- 管理后台
- 表单页面

```text
页面背景：#F5F8FC
卡片背景：#FFFFFF
主文字：#1F2D3D
次文字：#5F6F82
品牌主色：#002E5F
行动色：#FF5A45
```

建议平台主要功能页以浅色模式为主，避免用户长时间使用疲劳。

---

## 9. 禁用色彩规则

避免以下情况：

1. 不要大面积使用橙红色，否则会显得刺眼。
2. 不要使用传统大红 + 金色，会偏文旅纪念品风格。
3. 不要使用过多渐变，会削弱 Logo 的简约国际感。
4. 不要使用荧光蓝、荧光绿，会破坏品牌质感。
5. 不要在深蓝背景上使用低对比灰色小字，可读性不足。
6. 不要让按钮颜色过多，主操作统一橙红，普通操作用蓝色或白色。

---

## 10. 可直接给设计师 / AI 的配色提示词

> 整个平台 UI 采用深海蓝、白色和珊瑚橙红作为核心配色。深海蓝用于品牌背景、导航和关键视觉区域，白色用于主要文字、卡片和图标，珊瑚橙红只作为关键行动点和品牌记忆点使用，例如开始练习、录音状态、太阳图形和当前进度。功能页面以浅灰蓝背景和白色卡片为主，保持清爽、现代、国际化；品牌页面可使用深蓝大面积背景，营造专业、可信赖和轻科技感。整体避免传统中国风的大红大金，也避免过度渐变和复杂装饰，强调简洁、留白、清晰层级和高级感。
